# Ойлон (Team MIND) — подумай до подписи

AI-проверка микрозайма, рассрочки или потребкредита за 30 секунд: реальная (эффективная) ставка,
переплата, долговая нагрузка и объяснение простыми словами на русском или кыргызском + микро-урок.

**Проблема:** когда молодой человек в Кыргызстане берёт микрозайм или рассрочку, он видит «0,6% в день» или
«0% рассрочка», но не видит реальную цену денег и не понимает, сколько дохода съест платёж.

## Два режима
- **Проверка кредита** — AI читает предложение, формула считает реальную цену.
- **Игра «Үйгө жол»** (`game.html`) — 10 лет пути к своей квартире за 5 минут: ипотека, госпрограмма, рассрочка застройщика, курс сома, той, микрозаймы. Открывается в боковом меню; файл можно хостить и отдельно (GitHub Pages).

## Архитектура
```
SMS / реклама / фото договора
   → LLM (Gemini / Claude / OpenAI): ИЗВЛЕЧЕНИЕ условий в JSON      [ai.py]
   → человек подтверждает/исправляет поля
   → детерминированный расчёт: IRR → эффективная ставка, переплата, DTI, флаги   [engine.py]
   → LLM: ОБЪЯСНЕНИЕ цифр + урок (RU/KG), цифры не пересчитывает   [ai.py]
   → анонимная запись решения пользователя → logs/outcomes.csv (метрика: изменил ли решение)
```
AI не считает деньги — только читает и объясняет. Без API-ключа приложение работает в офлайн-режиме.

## Запуск локально
```bash
pip install -r requirements.txt
export GEMINI_API_KEY=...        # или ANTHROPIC_API_KEY / OPENAI_API_KEY
streamlit run app.py
python eval.py                   # точность извлечения + проверки формул
```

## Деплой
- **Streamlit Community Cloud** (проще всего): share.streamlit.io → Create app → репозиторий → `app.py` → Advanced settings → Secrets: `GEMINI_API_KEY = "..."`.
- **Hugging Face Spaces**: New Space → SDK **Docker** → загрузить файлы (Dockerfile уже есть) → Settings → Secrets: `GEMINI_API_KEY`.
- Утром 10 октября откройте ссылку заранее — бесплатный хостинг «засыпает».

Ойлон не является кредитором и не даёт юридических или инвестиционных гарантий.
